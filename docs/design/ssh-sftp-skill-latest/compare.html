重点比较这五件事，不要只比较颜色

  1. 01第一眼知道什么？文件本身，还是本次写入目的与目标？
  2. 02方向是否会看错？本机、SSH 通道和远端路径是否形成稳定关系？
  3. 03冲突结果可否预测？Keep both / Replace / Skip 之后，目录里究竟会出现什么？
  4. 04失败是否真的闭环？重试是按钮反馈，还是只恢复失败文件并到达完成？
  5. 05窄窗口还能不能做事？是压缩三栏，还是切换 Local/Remote 并保留 Manifest？
