Charter / Interaction study 07

同一个 Claude Code，四种完全不同的“抄法”

不要先管 PTY、TUI 这些词。只看一件事：用户在哪里打字。下面四个原型都能点；切换后请试试普通消息、/model 和权限确认。

一句话答案 想一行功能都不重做，就必须让真实终端在需要时露出来。
方案 3 - 漂亮输出 + 真实 TTY 输入 单独打开 ↗
方案 1 最稳开发量最低，CLI 新能力天然可用，但视觉仍然是终端。
方案 3 最符合你刚才的要求TTY 仍负责输入；Charter 只把输出重新排得更漂亮。
方案 4 最贵它不是藏起终端，而是绕过终端，因此所有交互都要自己维护。
